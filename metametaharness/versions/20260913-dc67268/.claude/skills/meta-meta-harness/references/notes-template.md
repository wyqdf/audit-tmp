# Notes template

```markdown
# Notes for <evaluated commit SHA>

Example note entries:
- <concise evolution reasoning and mechanism summary>
- <trace-derived summary of the run's behavior and important patterns> [[<trace/file ref>]]
- <additional important finding or analysis> [[<trace/file ref>]]
- ...
```

Rules:
- Notes bridge the commit message and raw traces/files.
- Capture key reasoning, actions, and mechanism details behind the evolution step.
- Summarize trace evidence into overall behavior, recurring patterns, and common problems.
- State whether the mechanism activated and worked.
- Cite the original trace/file/note wherever evidence exists; all trace-derived claims must be referenced.
